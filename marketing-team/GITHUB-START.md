# Arbeitsablauf

Ziel-Repository: https://github.com/maasho/voltage-africa-ai-ap

Issue mit Ziel, Stadt/Land, Marktseite, Sprache, Rolle und Abnahme → Facharbeit auf Aufgaben-Branch → Ergebnisbericht/PR → Qualitätsprüfung → autorisierte Übernahme.

Fachliche Regeln stehen in den zugeordneten Skills. Website-Änderungen gehören in den getrennten Website-Code. Dieser ist lokal als HTML/JS mit Supabase vorhanden; tatsächlichen Stand vor Umsetzung prüfen.

Das Board kann Backlog, Bereit, In Arbeit, Review und Erledigt verwenden. Eine Vorlage erzeugt kein Board und ein Issue startet keinen Agenten. Wiederholung wird erst bei einer tatsächlich eingerichteten Laufzeit ausgeführt.

Start mit einem Stadt-/Gewerkepilot nach docs/PILOT.md. Danach nach bestätigten Ergebnissen ausbauen.
