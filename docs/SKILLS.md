# Voltage-Africa-Skills

25 eigene repositorylokale Skills, ergänzt um sechs installierte externe Pakete (siehe INSTALLED-SKILLS.md): ein Primärskill je Rolle sowie Quellenprüfung und Lernen. Die [Teamübersicht](../marketing-team/TEAM.md) verlinkt alle 23 Fachskills; [skill-map.json](../marketing-team/skill-map.json) ist die maschinenlesbare Zuordnung.

Starte Aufgaben im Checkout dieses Repositorys, lies AGENTS.md und lade das passende SKILL.md. Beispiel: Nutze voltage-matching für docs/PILOT.md. Prüfe passende validierte Erkenntnisse in memory/INDEX.md und liefere belegte Ergebnisse mit Datenlücken.

[Lernen](../.agents/skills/voltage-learning/SKILL.md) bedeutet geprüfte Erkenntnisse in Dateien und versionierte Verbesserungen. Dies trainiert keine Modellgewichte und erzeugt keine Hintergrundläufe.

Die ursprüngliche Struktur wurde übernommen, alle 23 Fachskills wurden auf die Plattformaufgaben zugeschnitten. Die ausgewählten externen Pakete wurden auf Nutzerauftrag installiert; siehe [Installationsstand](INSTALLED-SKILLS.md). Weitere Kandidaten bleiben unter [Repository-Recherche](REPOSITORY-RESEARCH.md) dokumentiert.

Struktur prüfen: python scripts/validate_skills.py. [Fachliche Erprobung](SKILL-EVALUATION.md) erfolgt getrennt.
